Sheep MLT Builder

Converts the sheep catalogue spreadsheet into a NextLot MLT upload file.
v1.70
Output columns: Lot #, Lot Name, Description, Quantity, Starting bid and Reserve Price.
Custom: Uses the existing TAG-based sheep layout, horizontal trait groups and two-decimal-place indexes. The breeding-type field displays as RT; both RT and BT source columns are accepted.
Dorper: Accepts the supported Dorper catalogue layouts. The original format uses VID plus Sale Age / Lifetime Daily Weight Gain / Conception, sale scan, EP/PW, weaning and ASBV / Accuracy fields. The alternate format uses Lot, Name, Sex, Breed, Birth Date, TYPE, Weight, Sire, Dam, No.Born and BWT / WWT / PWWT / carcase / MCP / TCP / EQ fields. The top layout row is skipped when an actual field-name row follows it.
ASBV Download: Uses the animal's Name with a "Tag" prefix as the lot heading, displays SIRE and DAM as bold-labelled lines beneath POLL, and lists the available ASBV traits with their ASBV and accuracy values. Percentile is shown only if supplied by the spreadsheet.
Tick Include Sheep Genetics Link to add a clickable link below the trait tables. Select the Sheep Genetics group and then the relevant index/search scenario; the selected option determines the database/scenario used in every generated link. In ASBV mode, links use the 16-character animal Id supplied in the download. Custom uses one six-digit Stud/Flock ID and a six-character TAG/Tag No/VID/Visual ID. Dorper uses separate Dorper and White Dorper six-digit Stud/Flock IDs, selected automatically from Breed, plus a six-character TAG/Tag No/VID/Visual ID; alternate Dorper files extract that tag from Name. Letters and numbers are accepted in TAG/Tag No/VID, and hyphens are ignored when generating the link.
Lots are sorted by lot number in the preview and downloaded MLT, including after edits. Files without a Lot column receive sequential lot numbers; non-lot footer rows are ignored.
Output file: NextLot MLT (0 Lots).xlsx
Custom: upload a sheep catalogue with TAG, Tag No, VID or Visual ID, plus POLL, SIRE, DAM and measurement columns.
Six digits required for Custom files. Hyphens in TAG/Tag No/VID/Visual ID are ignored. Links use FFFFFFYYYYTTTTTT and the first two TAG digits for the year.
